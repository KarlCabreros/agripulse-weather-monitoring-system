🌾 AgriPulse – Weather & Farm Activity Monitoring System
📌 Overview

AgriPulse is a web-based farm monitoring and management system designed to help farmers and agricultural managers track farm activities, monitor weather conditions, and manage agricultural operations efficiently in real time.

It provides role-based access for owners, managers, and workers to ensure smooth coordination and transparent farm activity tracking.

🚀 Features
🌦️ Real-time weather monitoring integration
👨‍🌾 Farm activity management (Planting, Irrigation, Harvesting, etc.)
📊 Activity status tracking (Pending, In Progress, Completed)
👥 Role-based access control:
Owner
Manager
Worker
📝 Activity audit logs for transparency
📍 Location tagging for farm activities
🔔 Activity history and tracking system
🧾 Clean dashboard interface
🛠️ Tech Stack
Backend: Laravel (PHP Framework)
Frontend: Blade, Livewire
Database: MySQL
Authentication: Laravel Auth
Version Control: Git & GitHub
